# Guitar Tools v0.2.1

Android版に加えて、macOS版を実用できる形までまとめた最初の統合リリースです。

## Highlights

- Native SwiftUI interface with macOS sidebar/detail navigation
- CoreAudio input-device and channel selection
- Audio-interface hot-plug refresh and input-latency metadata
- YIN tuner with alternate/custom tunings and A4 calibration
- Metronome with subdivisions, accents, count-in, tap tempo and Speed Trainer
- 192-chord reference library
- 0–24 fret fretboard visualizer
- ChordWiki search and native chart rendering
- YouTube / anchor synchronization and piecewise time-warp
- ChordPro import and backing-track practice
- Live chord detection and onset timing feedback
- Persistent metronome, tuner, audio and practice settings
- Versioned practice-session storage for future analytics
- Packaged-app smoke tests and CI bundle validation

## macOS requirements

- macOS 14 or later
- Microphone / audio-input permission is required for tuner and live analysis
- Audio interfaces are optional; System Default Input can also be used

## macOS distribution

The macOS build is distributed as a DMG containing:

- `Guitar Tools.app`
- an `Applications` shortcut

The DMG is accompanied by a SHA-256 checksum.

The current build is **ad-hoc signed and not notarized with Apple Developer ID**. If macOS blocks the first launch, Control-click the app and choose **Open**.

## Android distribution

The same GitHub Release also contains the signed Android APK and SHA-256 checksum.

## Scope

Guitar Tools is a practice/analysis companion rather than a DAW. Recording, amp simulation, plug-in hosting, multitrack editing and mixing are intentionally outside the current scope.
