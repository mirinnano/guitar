# Guitar Tools v1.0.0

macOS版の譜面viewerで、ChordWikiの編集者ごとの書き方を読めるようにし、動画とのズレを直しやすくしました。

## macOSの変更

### 譜面の表示

- `[Am>]` のようなアクセント付きのコード、`[/B]` のようにベースだけを変える書き方を、コードとして表示。押さえ方の図も表示します。
- `[|]`、`[-- --]`、`[↓]` など、括弧で囲まれた小節線・リズム記号を記号として表示。
- 全角で書かれたコード名に対応。`<検索用>` の行は注記として扱い、再生時間に含めません。

### 譜面の時間配分

- 小節線の後の `x4` などの繰り返し回数を、再生時間に反映。
- 行の途中の拍子変更 `(3/4)`、`(5/8)`、`(6/8)` を小節の長さに反映し、次の変更まで引き継ぎます。
- `[C]---[G]-` のようなダッシュのリズム表記から、小節内のコードの位置を決定。
- 行頭の小節線で空の1小節が入っていた問題を修正。
- 歌詞から始まる行では、最初のコードまで前のコードを鳴らし続ける扱いに変更。
- 歌詞の後に小節線が続く行で、歌詞の部分を1小節に詰め込まないよう修正。

### 動画との同期

- 再生バーに「合わせる」を追加。コードが変わった瞬間に押すと、近いコードを動画のその時刻に合わせます（⌘J）。
- 動画の冒頭に無音や前奏がある場合は、最初のコードが鳴った瞬間に「ここを最初のコードにする」（⇧⌘J）。合わせた位置は曲ごとに保存します。
- 再生中にコードを⌥クリックしても、その時刻に合わせられます。
- 近い2点で合わせたときに、わずかな押し間違いが曲全体のズレに広がっていた問題を修正。合わせた範囲が4小節未満なら、その外側は譜面のテンポで進みます。合わせた点の間では、譜面のテンポ変更を保ちます。
- 前に合わせた位置と食い違う場合は、新しく合わせた位置を優先します。
- 譜面にBPMの記載がない曲では、BPMが仮の値であることを表示します。

### 動作の軽さ

- 再生中に譜面画面全体を毎フレーム作り直していた問題を修正。再生位置の表示だけを更新するようにし、再生中のCPU使用率を手元の計測で約90%から約25%に下げました。コマ落ちで表示が遅れて見える現象を抑えます。
- 再生バーを譜面の上に重ねて表示し、譜面のスクロールと独立させました。

譜面の時間配分は引き続き推定です。小節線のない歌詞の行は、設定の「小節線のない行」と「合わせる」で補正してください。動画の音声は解析しないため、無音区間は自動で検出しません。

## 配布

- Apple Silicon、macOS 14以降。Intel用の配布ビルドはありません。DMG内の `Guitar Tools.app` をApplicationsへコピーしてください。
- チューナーにはマイク／音声入力の許可が必要です。
- **Mac版はDeveloper ID未署名、Apple未公証です（ad-hoc署名）。** 初回起動時にmacOSがブロックする場合があります。[導入手順と安全上の注意](https://github.com/mirinnano/guitar/blob/main/docs/install-macos.md)を確認してください。
- 既存の統合リリース手順に従い、Android APKも配布します。今回Androidの機能変更はありません。
- 各配布ファイルのSHA-256チェックサムを添付します。
