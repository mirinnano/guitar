# Guitar Tools v0.2.0

macOS版の最初の実用プレビューです。Android版の主要機能をSwiftUIへ移植し、Macではオーディオインターフェース入力を使った演奏解析を追加しています。

## Highlights

- Native SwiftUI interface with a macOS sidebar / detail layout
- Metronome with 30–300 BPM, subdivisions, accents, count-in, tap tempo and Speed Trainer
- YIN tuner with alternate/custom tunings, A4 calibration and string lock
- 192-chord reference library and 0–24 fret fretboard visualizer
- ChordWiki search and native chart rendering with YouTube / anchor synchronization
- Practice mode with ChordPro import, backing tracks and timeline sync
- Live audio-interface chord detection and onset timing feedback
- CoreAudio input-device and channel selection with hot-plug refresh
- Persistent metronome, tuner, practice, audio-device and latency settings
- Versioned practice-session storage for future analytics
- Packaged-app smoke tests and code-signature validation in CI

## macOS requirements

- macOS 14 or later
- Microphone / audio-input permission is required for tuner and live analysis
- An audio interface is optional; the system default microphone/input can also be used

## Distribution note

This build is currently **ad-hoc signed and not notarized with Apple Developer ID**.

If macOS blocks the first launch, Control-click the app and choose **Open**. A future release will add Developer ID signing and notarization.

## Scope

Guitar Tools is intentionally a practice/analysis companion rather than a DAW. Recording, amp simulation, plug-in hosting, multitrack editing and mixing are outside the current scope.
