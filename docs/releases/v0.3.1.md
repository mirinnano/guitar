# Guitar Tools v0.3.1

macOS版を、譜面を見ながら気軽に弾ける構成に更新しました。

v0.3.0は公開前の検証で見送り、このバージョンに改善をまとめました。

## macOSの変更

- 新しいギターアイコンをアプリに設定。紹介画像、導入手順、不具合報告の入口を整備しました。
- 起動時は曲検索と最近開いた譜面を表示。「コード進行」「演奏判定」「コード判定」のタブを外し、譜面・チューナー・メトロノーム・コード・指板に絞りました。
- Liquid Glassの再生バーを譜面上に配置。検索・履歴とコード一覧の余白・文字の階層を整理し、譜面自体は不透明な背景で読みやすさを優先。macOS 26以降ではネイティブのLiquid Glassを使用し、旧OSでは標準マテリアルへ切り替えます。
- コードと歌詞の対応を保った折り返し、大きめの文字、文字サイズ切替、余白の調整。
- 右サイドパネルの「コード」タブに、曲内の使用コードと押さえ方の図を一覧表示。「設定」タブで表示・再生を調整。
- 歌詞部分で自動スクロールが速くなりすぎる問題を改善。Unicodeの小節線と休符小節に対応し、小節線のない行の長さを推定。手動設定は曲ごとに保存。
- 譜面に指定された曲中のテンポ変更を反映。再生中にBPMを変更しても現在位置を維持。
- U-FRETの譜面検索・読み込み、コード学習に対応。
- ChordWikiの「楽曲情報」にあるYouTubeリンクの取得先を修正。「鳥の詩」のように譜面本文に動画URLがない曲にも対応。
- チューナーのピッチ解析・追跡、入力停止時の表示更新、音声入力の開始・キャンセル操作を改善。

譜面の時間配分は推定です。実際の音源との同期には、必要に応じて開始オフセット・同期アンカーを調整してください。音源からの自動テンポ検出は行いません。

- CI負荷で揺らいでいた合成音声テストの時計を制御。実際のYIN解析と入力の期限切れ判定のテストは維持しています。

## 配布

- Apple Silicon、macOS 14以降。Intel用の配布ビルドはありません。DMG内の `Guitar Tools.app` をApplicationsへコピーしてください。
- チューナーにはマイク／音声入力の許可が必要です。
- **Mac版はDeveloper ID未署名、Apple未公証です（ad-hoc署名）。** 初回起動時にmacOSがブロックする場合があります。[導入手順と安全上の注意](https://github.com/mirinnano/guitar/blob/main/docs/install-macos.md)を確認してください。
- 既存の統合リリース手順に従い、Android APKも配布します。今回Androidの機能変更はありません。
- 各配布ファイルのSHA-256チェックサムを添付します。
