# macOS版の製品方針

## 現在の構成

Mac版は、譜面を見ながら好きな曲を弾くためのSwiftUIアプリです。
Android版と同じ画面構成に揃えることは目標にしません。
サイドバーは譜面、チューナー、メトロノーム、コード、指板の5項目です。
音声入力はチューナーに使用します。

## UIの判断基準

- 譜面を主役にし、練習の提案や採点を自動で始めない。
- 曲で使うコード図を常時見られるようにする。
- 設定は別タブにまとめ、譜面の表示を邪魔しない。
- ガラス表示は操作部に限定し、譜面は不透明な背景で読む。
- 狭い幅と大きな文字でも操作部が破綻しないようにする。
- 同期は推定であることを隠さず、手動補正を残す。

## 今後の候補

ユーザーの報告をもとに、外部譜面の表示互換性、テンポ変更の扱い、コード図の可読性を改善します。
Developer ID署名と公証、Intel向け配布は未対応であり、配布範囲を広げる際に検討します。
自動演奏評価、録音編集、ミキサー、プラグインホスト、アンプシムは現在の製品方針に含めません。
