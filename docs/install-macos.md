# Mac版の導入

## 配布状態

- Apple Silicon（Mシリーズ）、macOS 14以降向けのDMGです。Intel版は配布していません。
- Developer ID証明書を使用していません。Appleの公証も受けていません。
- ad-hoc署名は付いていますが、Appleによる開発者の身元確認や安全性の審査を意味しません。
- App Storeからの配布ではありません。

## ダウンロードとインストール

1. [公式GitHubリリース](https://github.com/mirinnano/guitar/releases/latest)で、バージョンと未公証の注意を確認します。
2. `Guitar Tools-X.Y.Z.dmg`と同じバージョンの`.sha256`をダウンロードします。
3. 必要に応じて、ターミナルでDMGのSHA-256を計算し、添付ファイルの値と比較します。

```bash
shasum -a 256 "$HOME/Downloads/Guitar Tools-0.3.1.dmg"
```

チェックサムは破損やファイルの違いを確認するためのものです。
配布元が侵害された場合の安全性まで保証しません。

4. DMGを開き、`Guitar Tools.app`を`Applications`へコピーします。
5. Applicationsからアプリを起動します。

## 初回起動がブロックされた場合

**警告の意味を理解し、配布元を信頼できると判断した場合に限って**起動を許可してください。
起動を試した後、「システム設定」→「プライバシーとセキュリティ」で、このアプリに対する「このまま開く」を確認できます。
詳しい条件と最新の手順は[Appleの公式案内](https://support.apple.com/ja-jp/102445)を参照してください。

Gatekeeper全体の無効化や、警告を一括で消すコマンドは推奨しません。
マルウェアや破損の警告が出た場合は起動せず、再ダウンロードや[問題の報告](https://github.com/mirinnano/guitar/issues/new/choose)を行ってください。
ダウンロード後の隔離属性付きDMGを別のMacで初回導入する手順は、まだ実機検証していません。

## 最初に曲を開く

1. 「譜面」で曲名またはアーティスト名を検索します。
2. 譜面を開き、右の「コード」タブで押さえ方を確認します。
3. ツールバーで文字サイズを調整します。再生と区間リピートは必要なときだけ使えます。

譜面を見るだけならマイク権限は不要です。
チューナーで「入力開始」を押すと、macOSが音声入力の許可を求める場合があります。
動画や譜面の取得にはインターネット接続が必要です。
